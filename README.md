# Employee Management System

A simple Employee Management System developed using C#, ASP.NET Core Web API and PostgreSQL.

## Features
- Add new employees
- View all employees
- Update employee details
- Delete employee records

## Technologies Used
- C#
- ASP.NET Core Web API
- PostgreSQL
- Entity Framework Core
- HTML
- CSS
- JavaScript

## Database
PostgreSQL is used to store employee details.

## Project Description
This application helps manage employee information such as name, age, gender, department, salary and email address.

## How to Run
1. Clone the repository.
2. Open the project folder in VS Code.
3. Configure your PostgreSQL connection using .NET User Secrets.
4. Run `dotnet restore`.
5. Run `dotnet run`.
6. Open the local URL displayed in the terminal.
